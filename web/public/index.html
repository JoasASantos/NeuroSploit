Model provider keys
The API keys for the LLMs that run the engagement (not the target's auth — that's the Target auth tab). Kept in this server process's memory only, never written to disk, cleared on restart.
The signed grant for this engagement: who authorized it, which hosts, which environment, until when. It is verified by the harness (NEUROSPLOIT_CAPABILITY_KEY) and acts as a ceiling — the settings below can narrow the scope, never widen it. Mint one with neurosploit capability issue.
Without this the engagement is authorized against the target and nothing else — discovering a host is not permission to test it.
